# 🛒 ShopSwift - MERN E-Commerce Application

ShopSwift is a full-stack e-commerce application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. It provides a complete shopping experience with product management, authentication, cart, orders, reviews, and payment integration.

## 🚀 Features

### User Features
- User registration and login
- Browse and search products
- Category-based filtering
- Product details and related products
- Add to cart
- Order placement
- Product reviews and ratings
- Online payment and COD support

### Admin Features
- Admin dashboard
- Add, update, and delete products
- Manage categories
- Manage inventory

## 🛠️ Tech Stack

**Frontend**
- React.js
- Context API
- Axios
- Bootstrap

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

**Additional Services**
- Cloudinary (Image Storage)
- Braintree Payment Gateway

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/ShopSwift.git

Install dependencies:

npm install
cd client
npm install

Create .env file:

MONGO_URL=
JWT_SECRET=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=

BRAINTREE_MERCHANT_ID=
BRAINTREE_PUBLIC_KEY=
BRAINTREE_PRIVATE_KEY=

Run the project in ShopSwift Folder:
npm run dev

Frontend:
http://localhost:3000

Backend:
http://localhost:8080
